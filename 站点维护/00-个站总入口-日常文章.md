# 个站总入口 / 日常文章

## 定位

个人站主入口，负责展示首页、生活、项目、关于、书单、工具、知识库、笔记等内容。

## 线上地址

- 主站：`https://hiwentao.com/`
- 工具页：`https://hiwentao.com/tools/`
- 笔记列表入口：导航中的“笔记”

## 常改位置

- 阅读笔记数据源：`src/data/readingNotes.ts`
- 首页：`src/pages/index.astro`
- 生活页：`src/pages/life.astro`
- 项目页：`src/pages/project.astro`
- 关于页：`src/pages/about.astro`
- 书单页：`src/pages/books.astro`
- 笔记文章：`src/pages/notes/`
- 文章交互组件：`src/components/DetailInteractions.astro`
- 全站内容配置：`src/data/content.ts`

## 维护原则

- 用户说“更新文章”“个站更新文章”，优先在 `src/pages/notes/` 新增或修改文章，并同步 `src/data/readingNotes.ts`。
- 首页阅读卡片和生活页金刚经条目由 `readingNotes.ts` 自动生成，不要再手写重复卡片。
- 未确认发布的文章放 `src/drafts/notes/`，不要放在 `src/pages/notes/`，否则 Astro 会直接生成线上路由。
- 不要顺手改小工具逻辑，除非用户明确说要改工具。
- 新文章如果需要出现在列表或首页卡片，要同步检查对应入口。

## 推荐分支

- 日常文章：`codex/note-YYYYMMDD-topic`
- 个站修复：`codex/site-fix-topic`
- 小工具更新：`codex/tool-name-topic`

原则：一个分支只做一类事；发文章不要混改小工具。

## 发布前命令

```bash
npm run site:prepublish
```

如果只想跑构建验证，不检查分支名：

```bash
npm run site:verify
```
